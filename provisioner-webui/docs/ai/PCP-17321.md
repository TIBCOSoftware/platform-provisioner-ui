# PCP-17321: Unreleased Feature Flag for Pipeline Options

## Summary

Add support for hiding pipeline option fields behind a feature flag. When a pipeline option has `unreleasedFeature: true` in its YAML config, the field is only visible if the pod environment variable `ENABLE_UNRELEASED_FEATURE=true` is set. Otherwise, the field is hidden from the UI.

## Background

Pipeline options are defined in YAML configuration files (e.g., `pp-deploy-on-prem-tp-gcp-k3s.yaml`) and loaded into the UI as form fields. Some fields may be under development and should not be visible to end users until they are ready. This feature provides a simple toggle mechanism controlled by an environment variable.

## Design

### Data Flow

```
YAML config (unreleasedFeature: true on option)
    ↓
K8s ConfigMap → Backend server
    ↓
/cic2-ws/v1/ui-properties (exposes ENABLE_UNRELEASED_FEATURE)
    ↓
Frontend PipelineView.vue (filters options before rendering)
    ↓
pipelinesOptions.vue (renders only visible options)
```

### Implementation Steps

#### 1. Backend: Expose Environment Variable

**File:** `server/routes/ws.js` (lines 136-141)

Add `'ENABLE_UNRELEASED_FEATURE'` to the `envVariables` array in the `/ui-properties` endpoint. This reuses the existing mechanism that already exposes `ON_PREM_MODE`, `NODE_ENV`, etc.

```javascript
const envVariables = [
  'ON_PREM_MODE', 'PIPELINES_CLEAN_UP_ENABLED', 'NODE_ENV',
  'GIT_BRANCH', 'GIT_COMMIT', 'BUILD_TIME', 'DOCKERFILE',
  'PIPELINE_TEMPLATE_LABEL_KEY_ACCOUNT', 'PIPELINE_TEMPLATE_LABEL_KEY_ACTION',
  'PIPELINE_TEMPLATE_LABEL_KEY_CREATE_BY', 'PIPELINE_TEMPLATE_LABEL_KEY_NOTE',
  'ENABLE_UNRELEASED_FEATURE'  // <-- add this
];
```

#### 2. Type Definition

**File:** `src/types/pipeline.d.ts`

Add optional field to `PIPELINE_OPTION` interface:

```typescript
export interface PIPELINE_OPTION {
  // ... existing fields ...
  unreleasedFeature?: boolean;
}
```

#### 3. Frontend: Filter Options

**File:** `src/views/PipelineView.vue`

Before calling `formatPipelineGroups()`, filter out options with `unreleasedFeature: true` when the feature flag is not enabled:

- Call `utils.getUiProperties()` to get `ENABLE_UNRELEASED_FEATURE` value
- If `ENABLE_UNRELEASED_FEATURE !== 'true'`, filter: `options.filter(opt => !opt.unreleasedFeature)`
- Filtering happens before `formatPipelineGroups()` so hidden options don't appear in any step group

#### 4. YAML Configuration (Example)

**File:** `cicinfra-cic2-provisioner-webui/charts/provisioner-config-cloud/config/menu-deploy-on-prem-tp/pp-deploy-on-prem-tp-gcp-k3s.yaml`

Add `unreleasedFeature: true` to the target option (e.g., under "GCP Region"):

```yaml
- name: "GCP Region"
  reference: "meta.guiEnv.GUI_GCP_REGION"
  type: "string"
  guiType: "input"
  unreleasedFeature: true
```

## Testing

### Unit Tests

#### Frontend: `src/views/PipelineView.test.ts`
Tests the `filterUnreleasedOptions` logic extracted from `PipelineView.vue`:
- Returns all options when flag is off (no filtering)
- Hides options with `unreleasedFeature: true` when flag is on
- Returns all options when none have `unreleasedFeature`
- Returns empty array when all options are unreleased and flag is on
- Handles empty options array

#### Backend: `server/routes/ws.test.js`
Tests the `/ui-properties` endpoint (added to existing test file):
- Verifies GET `/ui-properties` route exists on the public router
- Returns `ENABLE_UNRELEASED_FEATURE` value from env when set
- Returns empty string when `ENABLE_UNRELEASED_FEATURE` is not set

### E2E Test: `e2e/unreleased-feature.spec.ts`
Playwright test that validates the full flow:
1. Fetches `/cic2-ws/v1/ui-properties` to check the flag value
2. Navigates to the pipeline page (step #2 "Cloud Provider")
3. Verifies "GCP Region" field visibility matches the flag state:
   - Flag enabled → field hidden
   - Flag not set → field visible

### Running Tests

```bash
# Unit tests
npm run test:unit:ui

# E2E tests (requires local deployment)
npx playwright test e2e/unreleased-feature.spec.ts

# Type check and build
npm run type-check

```

### Manual Verification

Tested locally by toggling the env var on the running pod:
```bash
# Enable flag (hides unreleased fields)
kubectl set env deployment/platform-provisioner-ui ENABLE_UNRELEASED_FEATURE=true

# Remove flag (shows all fields)
kubectl set env deployment/platform-provisioner-ui ENABLE_UNRELEASED_FEATURE-
```

## Deployment Notes

- To enable unreleased features on staging/production, set `ENABLE_UNRELEASED_FEATURE=true` in ArgoCD Helm values:
  ```yaml
  guiConfig:
    enableUnreleasedFeature: "true"
  ```
- The deployment manifest in `cicinfra-cic2-provisioner-webui` must pass this as an env var to the pod
